## 1. 데이터를 처음 보는 팀원을 위한 배경 및 구조 설명

### (1) 데이터의 정체와 수집 단위
- **어떤 데이터인가?**: 국내 중소 제조기업(OKM)의 실제 생산 설비에서 수집된 **전력 소비량(kW), 완제품 생산량, 공장 투입 인원, 외부 날씨(기상청 데이터 연계), 전기 요금 정보**가 통합된 시계열 데이터셋입니다.
- **수집 기간**: **2021년 1월 1일 약 2021년 9월 14일 (총 257일간)**
- **행(Row)의 의미**: 데이터의 **1개 행은 정확히 '1시간(Hour)'**을 나타냅니다.
  - 하루 24시간 × 257일 = **총 6,168개 행**으로 구성되어 있으며, 단 하루나 한 시간의 누락 없이 연속적입니다.

### (2) 18개 원본 컬럼 상세 사전

| | `강수량` | float64 | mm (0.0-122.4) | 시간별 누적 강수량 |

## 3. 적용된 전처리 기법 및 도메인 근거 상세 요약

| 전처리 항목 | 원본 문제점 | 적용된 처리 방법 | 도메인/통계적 근거 |
| :--- | :--- | :--- | :--- |
| **날짜 (Dtype)** | int64 (`20210101`) | `datetime64[ns]` 변환 | 표준 시계열 인덱싱 및 날짜 연산 지원 |
| **컬럼 명칭** | `day`, `d`, `m` | `요일`, `일`, `월`로 한글 표준화 | 팀원 간 의사소통 명확화 (ISO 요일 1:월 ~ 7:일 확인) |
| **시간 이상치** | 7/13, 7/15의 48개 행에 70-188 비정상값 기록 | `시간_raw` 영구보존 + `시간_복원여부` 플래그 + 행순서 0 ~ 23시 재부여 | 기온 일변화 곡선 검증 결과 24개 행 정렬 순서가 정상 시간과 100% 일치 |
| **공장인원 결측** | 8/28 18시 ~ 8/29 10시 17시간 연속 결측 | **0.0 으로 대체** | 해당 기간 전력 0 kW(셧다운), 생산량 0. 전체 데이터셋에서 생산량=0 ↔ 공장인원=0은 100% 완벽 일치 |
| **풍속 결측** | 6/1(2건), 7/4(1건) 국소 결측 | **시간 기준 선형 보간** | 대기 물리량의 시간적 연속성 반영 (왜곡 최소화) |
| **강수량 결측** | 1/24 00시 1건 결측 | **선형 보간 (3.15 mm)** | 직전 23시(6.3mm)에서 01시(0.0mm)로 비가 그쳐가는 감쇠 전이 과정 반영 |
| **공장 셧다운 식별** | 비정상 정전/셧다운 구간 (전력 0 kW) | **`공장_셧다운_여부` 불리언 플래그 생성** | 시계열 연속성을 위해 행 삭제는 하지 않되, 모델 학습 시 마스킹 또는 가중치 조절이 가능하도록 분리 |
| **전력 평균 정밀도** | 원본 `평균` 컬럼의 반올림 오차(±0.25 ~ ±0.5) | **`전력_평균_실수` (float64) 컬럼 추가** | 4개 구간 산술평균을 정밀 계산하여 반올림 오차를 원천 제거하고 기존 컬럼 호환성 유지 |

## 4. 팀원 재현 및 코드 사용법

다른 팀원들은 번거로운 전처리 과정을 반복할 필요 없이, 아래 두 가지 방법 중 원하는 방식으로 완벽히 정제된 데이터를 즉시 가져올 수 있습니다.

### 방법 1. 정제 데이터 직접 로드 (가장 권장 - 1초 소요)
저장된 CSV 파일(`data/okm_cleaned_2021.csv`)을 바로 읽어옵니다. (파일이 없을 경우 파이프라인 자동 실행)
```python
from src.preprocessing import load_cleaned_data

# 정제 완료 데이터셋 로드 (날짜 datetime 파싱 및 UTF-8-SIG 한글 자동 처리)
df_clean = load_cleaned_data()

print(df_clean.shape)                  # (6168, 22) 출력
print(df_clean.isnull().sum().sum())   # 0 출력 (결측치 0개 완벽 정제)
print(df_clean.head(3))
```

### 방법 2. 원본 데이터 기반 전처리 파이프라인 전체 재현
원본 CSV(`data/okm_augumented_2021.csv`)로부터 모든 결측치/이상치 정제 로직을 다시 수행하고 파일로 재저장합니다.
```python
from src.preprocessing import run_preprocessing_pipeline

# 원본 데이터 로드 -> 날짜/컬럼 표준화 -> 시간 복원 -> 결측치 보정 -> 정제 플래그 생성 -> 파일 저장 원스톱 실행
df_clean = run_preprocessing_pipeline(save_output=True)
```

> 💡 **엑셀(Excel) 사용자 참고**: 저장된 CSV 파일은 `utf-8-sig` 인코딩으로 저장되어 있어 Windows 엑셀에서 더블클릭으로 바로 열어도 한글 컬럼명이 깨지지 않습니다.
