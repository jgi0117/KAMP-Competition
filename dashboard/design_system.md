# AI 전력 피크 대시보드 디자인 시스템

이 문서는 1단계 디자인 기반의 기준 문서다. 화면 구조와 기능은 후속 단계에서 다루며, 현재 단계에서는 모든 화면이 같은 시각 언어를 사용하도록 토큰과 상태 표현을 정의한다.

## 1. 디자인 방향

- 단일 테마: 다크 모드 전용
- 분위기: 프리미엄 산업용 관제 시스템
- 핵심 팔레트: 차콜 + 그레이 + 틸
- 강조 원칙: 평상시에는 저채도, 상태 변화와 핵심 수치에만 고채도 사용
- 정보 원칙: 색상만으로 상태를 전달하지 않고 아이콘, 상태명, 수치를 함께 표시

## 2. 색상 토큰

| 역할 | 토큰 | 값 | 사용 기준 |
| --- | --- | --- | --- |
| 앱 배경 | `--background` | `#080f17` | 전체 캔버스 |
| 기본 패널 | `--surface` | `#111e2a` | 카드, 필터, 표 |
| 상승 패널 | `--surface-raised` | `#162532` | 버튼, 보조 요소 |
| 기본 텍스트 | `--text` | `#e8eef2` | 본문과 라벨 |
| 강한 텍스트 | `--text-strong` | `#f8fbfc` | 핵심 수치와 제목 |
| 보조 텍스트 | `--muted` | `#aebdc9` | 설명과 메타 정보 |
| 브랜드/선택 | `--teal` | `#22c7b8` | 선택, 활성, 주요 행동 |
| 정상 | `--status-normal` | `#36c98f` | 정상 상태 |
| 주의 | `--status-caution` | `#f5b942` | 주의 상태 |
| 위험 | `--status-danger` | `#ff5d68` | 위험과 즉시 대응 |
| 정보 | `--status-info` | `#4c8dff` | 설명과 중립 정보 |

위험색은 위험 배너, 위험 수치, 위험 상태 배지, 위험 행동 버튼에만 사용한다. 일반 탐색이나 장식에는 사용하지 않는다.

## 3. 타이포그래피

- 서체 순서: Pretendard → SUIT → Noto Sans KR → 맑은 고딕 → 시스템 서체
- 페이지 제목: 24–34px, 굵게, 자간 축소
- 섹션 제목: 19px, 굵게
- 본문: 15px
- 보조 정보: 12–13px
- KPI 수치: 24–38px, 굵게, 고정폭 숫자 사용

외부 폰트 다운로드 없이 설치된 서체를 우선 사용한다. 운영 PC에 Pretendard나 SUIT가 없으면 다음 한글 시스템 서체로 자동 대체된다.

라이트 모드는 제공하지 않는다. 배경, 차트, 입력 컴포넌트 및 상태 표현은 모두 다크 환경을 기준으로 검증한다.

## 4. 간격과 형태

- 간격 체계: 4 / 8 / 12 / 16 / 20 / 24px
- 작은 모서리: 7px
- 기본 모서리: 10px
- 카드 모서리: 12px
- 카드는 얇은 테두리와 낮은 그림자를 사용한다.
- 선택 행은 틸 배경과 왼쪽 강조선으로 구분한다.

## 5. 컨트롤 상태

- 기본 버튼: 틸 배경, 어두운 텍스트
- 보조 버튼: 상승 패널 배경, 얇은 테두리
- 위험 버튼: 위험색 배경, 명시적인 위험 문구와 함께 사용
- 비활성 컨트롤: 투명도를 낮추고 툴팁으로 비활성 이유를 안내
- 키보드 포커스: 밝은 틸 외곽선과 포커스 링 표시
- 눌림 상태: 1px 아래 이동

## 6. 차트 공통 기준

- 실제값: 밝은 회색 또는 흰색 계열의 실선
- 예측값: 틸 실선
- 미래 구간: 틸 점선과 낮은 투명도의 신뢰 구간
- 기준선/임계값: 주의는 앰버, 위험은 레드
- 차트 배경은 패널과 동일하게 유지하고 축/그리드는 낮은 대비로 표현
- 비교 단위, 시간 범위, 범례 명칭은 화면 간 동일하게 유지

1단계에서는 모든 차트의 공통 글자, 축, 그리드, 호버 색상을 확정한다. 개별 계열의 의미색과 상호작용은 해당 화면을 다루는 후속 단계에서 조정한다.

## 7. 움직임 기준

- 일반 전환: 140–220ms
- 강조 전환: 420ms
- 위험 배너: 위험 상태 진입 시 3회 점멸 후 정지
- KPI: 값이 갱신될 때 숫자 카운트업과 1회 카드 강조
- `prefers-reduced-motion` 사용자는 모든 애니메이션을 사실상 비활성화

위험 배너, KPI 강조, 페이지 전환, 드로어 및 스켈레톤 애니메이션을 현재 프로토타입에 연결한다.

## 8. 로딩·빈 상태·오류

- 로딩: 움직이는 스켈레톤 블록
- 빈 상태: 점선 테두리 카드와 명확한 빈 상태 문구
- 오류: 위험색 테두리와 배경, 원인 및 재시도 안내
- 측정값 0, 데이터 없음, 로딩 중, 오류를 서로 다른 상태로 취급한다.

## 9. 접근성과 반응형 원칙

- 텍스트와 배경의 충분한 대비를 유지한다.
- 상태를 색상만으로 구분하지 않는다.
- 모든 인터랙티브 요소에 키보드 포커스를 표시한다.
- 좁은 화면에서는 정보 우선순위를 유지한 채 열을 줄이며, 수치와 단위를 분리하지 않는다.
- 사용자가 모션 축소를 설정한 경우 점멸과 강조 애니메이션을 최소화한다.

## 10. 확정된 화면 구성

- 위험 배너에는 상태와 1시간 최대 예상 전력만 표시한다.
- 대표 KPI는 `1시간 최대 예상 전력`과 `피크 위험 확률`을 한 카드에 묶는다.
- 현재 실제 전력, 1시간 평균 예상, 위험 기준값은 보조 KPI 3개로 배치한다.
- 홈 차트는 6시간을 기본으로 하며 12시간과 24시간 범위를 제공한다.
- 전력 추이의 선택 시점은 피크 예측 기여 요인 패널과 기여·점검 화면에 전달한다.
- `원인`이라는 단정적 표현 대신 `피크 예측 기여 요인`을 사용한다.
- 1440px 이하에서는 사이드바를 자동 축소하고 사용자가 다시 펼칠 수 있게 한다.
- 1920px와 1280px를 핵심 검증 해상도로 사용한다.
- 모델 성능은 탭 없이 한 화면에 구성하되, 실제 회귀 성능을 위에 두고 시뮬레이션 검증을 아래에 둔다.
- 조치 상세 패널은 스티키로 유지하며, 홈의 조치 등록은 오른쪽 드로어에서 수행한다.

## 11. Test 재생 상호작용

- 재생·일시정지 버튼은 5초마다 저장된 Test 시각을 1시간씩 이동한다.
- 경보음은 초기 음소거 상태이며, 사용자가 켜면 위험 경보음을 3회 재생한다.
- AI 추천 조치는 배지만 제공하며 자동 선택하지 않는다.
- 사용자는 조치를 하나 이상 직접 선택해야 저장할 수 있다.
- 저장된 조치는 세션 저장소에 추가되고 조치 관리 목록에 표시된다.
- 실제 추론, 스트리밍 경보 판정 및 영구 저장은 운영 파이프라인 연결 후 교체한다.

## 12. Test 관제 화면 Industrial AI Control v2

- Test 관제 홈은 장식형 카드 대신 `경보 이벤트 스트립 → 5개 지표 레일 → 전력 타임라인/변수 중요도` 순서로 구성한다.
- 패널 모서리는 4px, 버튼과 상태 요소는 2~4px를 사용하며 카드 그림자와 장식용 그라데이션을 사용하지 않는다.
- 청록색은 예측·선택·정상 데이터 링크, 백색은 실제값, 황색은 기준값, 적색은 위험 상태와 기준 초과에만 사용한다.
- 상단 헤더는 `TEST REPLAY`, 데이터 재생 상태, 1시간 간격, 재생 시각을 구분해 표시한다.
- 전력 차트에는 현재 시점선, 예측 구간 음영, 위험 기준 밴드와 예상 피크 시점·값을 함께 표시한다.
- 1280px에서는 사이드바가 축소되더라도 모든 내비게이션 아이콘을 유지한다.
- 저장된 Test 산출물임을 명시해 시스템 상태를 실제 운영 상태로 오해할 수 있는 문구를 사용하지 않는다.

## 13. 분석·모델·조치 화면 관제형 확장

- 모든 하위 화면은 `영문 시스템 코드 + 한글 화면명 + 상태 표시` 헤더를 공통으로 사용한다.
- 기여·점검 화면은 트리 모델별 Test permutation importance와 상위 변수 검증 근거를 한 흐름으로 배치한다.
- 모델 화면은 실제 회귀 Test 결과와 저장된 예측의 피크 경보 지표를 화면 상단부터 명확히 분리한다.
- 조치 화면은 미확인·처리 중·완료·평균 처리시간을 지표 레일로 제공하고, 목록과 상세를 같은 화면에서 확인하도록 한다.
- 표 헤더, 상태 코드, 분석 기준 시각에는 고정폭 글꼴을 사용하고 패널 반경은 4px로 통일한다.
- 연결되지 않은 점검 완료·조치 시작·CSV 내보내기는 비활성 상태와 활성화 조건을 함께 제공한다.
- 조치 기록은 현재 브라우저 세션 저장임을 표시하며 영구 저장으로 오인하게 만드는 문구를 사용하지 않는다.
